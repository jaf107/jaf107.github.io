RepairA11y

Repairing Focus-Behavior Violations from Runtime Evidence

Automatically repairs the WCAG 2.4 focus-behavior violations that NavA11y detects.

LLM
Code→

How it works

  • Input: a violation from NavA11y, with the runtime evidence recorded during detection.
  • Output: a typed patch (a CSS rule or an attribute change, never free-form code).
  • Generators: WCAG-based rules, or a language model.
  • Verification: the patch is applied in a live browser and NavA11y's checks run again.

Example repair

Results on 32 test cases

  • Rules fixed 29; the language model fixed 25.
  • No patch introduced a new focus-behavior violation.
  • Runtime evidence raised the model from 5 to 7 of 7 realistic focus-appearance cases, but lowered it on obscuration cases.
  • Samples are too small for statistical significance.
