NavA11y

Detecting Focus-Behavior Violations through Dynamic Analysis

Finds WCAG 2.4 keyboard focus-behavior violations by driving a real browser.

Paper→DOI→Code→

How it works

  • Drives real keyboard navigation in Chromium through Playwright.
  • Page level: compares the HTML source order, the tab sequence focus actually takes, and the visual reading order (SC 2.4.3).
  • Element level: compares how each element is drawn before and after focus, and checks whether other content, such as a sticky header, covers it (SC 2.4.7, 2.4.11, 2.4.12, 2.4.13).
  • Reports as JSON, HTML, and annotated screenshots.

Found on real sites

Results

  • 100% precision and recall on a 22-page labeled benchmark (32 success-criterion assertions).
  • 2,947 violations found across 26 production websites.
  • 90% precision, confirmed by two independent expert raters.
  • First tool to cover all five WCAG 2.4 focus-behavior success criteria.
  • The labeled dataset is released for benchmarking.
